# Advanced Course: CMU 15-721 + PostgreSQL Internals

This is a watch-and-read plan. It has no coding projects. You can finish it on an iPad.
Start it after the [intro course](intro-15-445.md).

Each row is one week. Do the four items in this order:

1. Watch lecture A.
2. Watch lecture B.
3. Read the PostgreSQL Internals chapters. Compare the PostgreSQL design with the lecture topic.
4. Read the external paper or blog.

A week takes about 5-6 hours. Lectures are about 75 minutes each. The book reading is 20-40 minutes.
The external read is 45-90 minutes, because the papers are dense. If a week runs long, read the
introduction, the design sections, and the conclusion of the paper first.

## Notes on the plan

- **Light book match:** PostgreSQL Internals covers a row-store OLTP system. Weeks 1-3 and 8-11 cover
  columnar and cloud warehouse topics that the book does not cover. In those weeks the book
  readings show the closest PostgreSQL feature. Use them to see how PostgreSQL differs.
- **Week 11 review:** This week has one lecture. Use the free time to re-read the lecture
  slides that you found hardest.
- **Optional recall:** After each lecture, write three sentences from memory. This is not required.
